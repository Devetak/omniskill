# omniskill

Call with `$omniskill`.

I usually tell Codex the same things:

- use ASD-STE100 English
- use Luna subagents
- make it simple
- ask if unsure

so i made a skill.

## Install

```bash
mkdir -p ~/.codex/skills
gh repo clone Devetak/omniskill ~/.codex/skills/omniskill
```

Update later with:

```bash
cd ~/.codex/skills/omniskill
git pull
```

Best used with [Ponytail](https://github.com/DietrichGebert/ponytail) for coding-heavy work.
